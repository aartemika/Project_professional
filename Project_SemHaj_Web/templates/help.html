Справка по кадровому навигатору

Начало работы

Запустите сервер, войдите под учётной записью из .env. Администратор открывает раздел «Админка», выбирает CSV и нажимает «Заменить набор». Затем доступны аналитика, просмотр вакансий и экспорт PDF. Оконный клиент подключается к этому же серверу по HTTP.

Фильтры и сравнение

Выберите профессиональную область, затем один или несколько городов. Для сравнения укажите 2–3 города. Пустой выбор означает все города. Кнопка сброса возвращает полный набор. Кластеры пересчитываются для выбранной области на всех городах; выбор городов не меняет базу нормирования индекса.

Метрики

Количество вакансий — число уникальных vacancy_id. Медианная зарплата — медиана среднего нижней и верхней границ в рублях для месячных предложений; при одной границе используется она. Пересчёт валют использует готовые столбцы salary_from_rub и salary_to_rub. Начисление до или после налогов в источнике может различаться. Число известных значений показано в таблице.

Среднее число откликов считается по непустым responses_count. Отклики не являются числом уникальных соискателей; поле total_responses_count не смешивается с responses_count. Доли удалённого, офисного и гибридного форматов рассчитываются по отдельным признакам, поэтому могут пересекаться.

Относительный индекс спроса = 100 × число вакансий города / максимальное число вакансий среди городов выбранной области. Он описывает объём спроса в данном снимке и не измеряет кадровый потенциал или дефицит специалистов.

Кластеризация

Простой k-means объединяет города по числу вакансий, медиане зарплаты, средним откликам и доле удалённой работы. Признаки стандартизуются; отсутствующие зарплата и отклики для кластеризации заменяются нулём. Не более трёх групп; начальные центры фиксированы. «Группа 1» не означает лучший город. Малый размер выборки и пропуски ограничивают интерпретацию.

Ограничения источника

Загружается один CSV за раз; снимки не суммируются. Дубли vacancy_id удаляются с сохранением последнего снимка по snapshot_date, затем последней строки. Отсутствующие обязательные значения исключаются. Нет отдельных полей Hard Skills, активных резюме и проверенной временной серии: эти показатели не рассчитываются. Профессиональная область описывает вакансии, а не отрасль работодателя. Рекомендации являются описательным сравнением, не прогнозом.

Администрирование и ошибки

Администратор создаёт пользователей, меняет пароль, блокирует доступ, выполняет CRUD пользователей, справочников, вакансий и журнала и заменяет набор данных. Повторный импорт восстанавливает справочники из файла. Аналитик не имеет доступа к админке. При недоступности сервера проверьте адрес и порт. Токен оконного клиента действует один час; после истечения войдите заново. PDF содержит рекомендацию и четыре графика. Контакты сопровождения указаны на отдельной странице.
