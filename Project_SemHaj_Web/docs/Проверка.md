# Проверка проекта

Дата: 30.10.2026. Среда: Windows, Python 3.14, Flask 3.1.3, Flask-SQLAlchemy 3.1.1, SQLAlchemy 2.1.6, PySide6-Essentials 6.12.0, pandas 3.1.0, matplotlib 3.11.2.

## Автоматические проверки

Команда из корня: `.venv\Scripts\python.exe -m pytest -q`. Результат: **13 passed**.

Проверены медиана зарплат, пропуски, отклики, доля удалённого формата, индекс по общей базе городов, дедупликация и исключение почасовых зарплат; API авторизация, блокировка пользователя, разграничение ролей, CSRF и HTTP ошибки; PNG и PDF; полный цикл CRUD каждой таблицы, внешние ключи и неотрицательные числа; сохранность БД при пустом файле и откат при сбое внутри транзакции.

## Реальные файлы

Очищенный файл: 99 653 вакансии, 9 городов, 27 областей, 94 976 известных месячных зарплат. Исходный файл: 129 464 вакансии, 722 населённых пункта, 27 областей, 98 183 известных зарплат. Пересечение ID — 99 653. Выполнены обе команды исследования и сравнение через текстовое меню. SQLite заполнена очищенным файлом.

## Интерфейсы

Qt проверен с настоящим локальным HTTP сервером: вход через форму, справочники, таблица девяти городов, график, справка, сравнение двух городов, загрузка CRUD списка, создание тестового города через форму и удаление через API. Тестовые записи удалены.

Браузер проверен в Chrome: вход, все графики, админка, поиск вакансий, сравнение двух городов и PDF. Через браузерную форму выполнены создание, изменение и удаление тестового города. Ошибок JavaScript нет, запросов к внешним ресурсам нет. CSS, Bootstrap и jQuery загружаются локально.

Проверена загрузка форм .ui, отдельных QSS/CSS и наличие docstring и аннотаций у всех функций и классов. Пять схем успешно сгенерированы локальным PlantUML. Документы экспортированы через Word для визуальной проверки; все страницы осмотрены после окончательной вёрстки.

Это функциональная проверка учебного локального решения. Нагрузочное тестирование и статистическая валидация кластеров не выполнялись.
