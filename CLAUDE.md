Пользователь — новичок, пишет по-русски. Объяснять простыми словами, без жаргона, с аналогиями. Работает вместе с девушкой.

## Проект
«Экономико-кадровый навигатор». Две рабочие папки:
- `Project_SemHaj_Web` — сайт на Flask + SQLite (`data/navigator.db`).
- `Project_SemHaj_Desktop` — оконное приложение PySide6 + консольный анализатор. Ходит на сайт по HTTP.

Старая папка «наш проект» заброшена, её не трогать. Главные данные — `final_clean` CSV (чистила девушка).

## Выбранная тема
Специализация крупных городов: кого каждый город ищет чаще остальных (коэффициент специализации = доля категории в городе / доля категории по всем городам).

## Как запускать
- Двойной клик по `run.bat` в нужной папке. Он сам создаёт `.venv` и ставит библиотеки (нужен Python 3.10+, интернет при первом запуске).
- Сайт: http://127.0.0.1:5000, браузер открывается сам.
- Вход без пароля: `AUTO_LOGIN=1` в `.env`, на сайте красивая кнопка «Войти»; после «Выйти» обычная форма.
- Работать можно с двух компьютеров (дом и ноут) через GitHub; `.venv` у каждого своя и в GitHub не попадает.

## Что уже сделано
- Автовход и страница приветствия; автооткрытие браузера.
- Интерактивная карта России на главной (Leaflet, работает без интернета): без фильтров цвет = доля вакансий города, с фильтром категории = коэффициент специализации.
- Карта обновлена: градиентный цвет, размер кружка = число вакансий (радиус 9–15 px, больше нельзя: Краснодар и Ростов начнут налезать), карточка при наведении. Класс `row` в карточке занят Bootstrap, поэтому там `line`.
- Вход: при каждом запуске сервера старые входы сбрасываются (`BOOT_ID`), поэтому кнопка «Войти» видна всегда.
- Красивые графики (вариант 2) на сайте.
- Универсальный запуск: `run.bat` + `prepare_env.bat`, `.gitattributes` (`*.bat` в CRLF).

## Особенности данных
