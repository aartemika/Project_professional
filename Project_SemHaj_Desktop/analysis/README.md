# Консольный анализ
Из корня соответствующего приложения: `.venv\Scripts\python.exe analysis\analyze.py`.
Меню позволяет выбрать CSV, исследовать все файлы отдельно либо сравнить их состав и пересечение ID.
Результаты в `analysis/results`: quality.json, report.txt, таблицы CSV и графики PNG.
Парсер аргументов командной строки не используется. Сервер и Qt не нужны для выполнения скрипта.
