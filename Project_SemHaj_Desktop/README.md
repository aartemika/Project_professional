# Экономико-кадровый навигатор — оконное приложение

Интерфейс на PySide6, HTTP запросы через requests, графики matplotlib. Сервер Flask запускается отдельно из Project_SemHaj_Web. Консольный анализатор работает без сервера.

## Структура

```text
main.py                 запуск приложения
source/                 весь прикладной Python код
  main.py               окна и фоновые запросы
  api_client.py         HTTP клиент
  admin.py              редактор данных
  charts.py             графики matplotlib
  dataset.py            подготовка CSV
  config.py             адрес сервера
ui/                     отдельные формы Qt Designer
resources/              style.qss и help.html
analysis/               отдельный консольный скрипт и результаты
data/                   исходные CSV
docs/                   пояснительная записка и схемы
```

Структура соответствует разделению учебного Qt шаблона: точка входа в корне, Python модули в source, формы в ui, оформление и справка в resources. Название pycode не используется.

## Запуск

При первой установке запустите setup.bat. Затем запустите Flask из Project_SemHaj_Web и откройте run.bat в этой папке. В терминале: `.venv\Scripts\python.exe main.py`.

Адрес сервера задан в source/config.py: SERVER_URL = "http://127.0.0.1:5000". Его можно изменить в Python файле или в окне входа. Клиентский .env не используется. Логин и пароль создаются на Flask сервере; первоначальные данные администратора находятся в Project_SemHaj_Web/.env.

Для анализа CSV запустите run_analysis.bat либо `.venv\Scripts\python.exe analysis/analyze.py`. Меню предлагает исследовать один файл, все файлы отдельно или сравнить их состав. Результаты сохраняются в analysis/results.

## Работа

Выберите область и города, нажмите «Применить». Для сравнения отметьте 2–3 города. Графики открываются на отдельной вкладке и сохраняются в PNG/PDF. Кнопка «Справка» открывает локальную инструкцию.

Администратору доступно «Управление данными»: создание, просмотр, изменение и удаление пользователей, городов, областей, форматов, вакансий и записей журнала. Списки поддерживают поиск и страницы по 30 записей. Сервер проверяет права и связи; нельзя удалить используемый справочник или собственную учётную запись. Пустой пароль при редактировании пользователя сохраняет прежний.

Обозначение desktop_app в общей пояснительной записке соответствует этой папке Project_SemHaj_Desktop; актуальная структура приведена выше. Код распространяется по MIT, условия находятся в LICENSE.
