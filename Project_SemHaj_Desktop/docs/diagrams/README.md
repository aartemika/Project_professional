# Схемы PlantUML
Все подписи на русском. Исходники .puml и изображения .png находятся рядом.
01 — варианты использования; 02 — компоненты; 03 — последовательность работы клиента;
04 — импорт данных; 05 — развёртывание. ER-диаграмма намеренно не включена по заданию автора.
Для повторной генерации установите Java и PlantUML и выполните:
`java -jar plantuml.jar -charset UTF-8 -tpng docs/diagrams/*.puml`
Для диаграмм компонентов и развёртывания может потребоваться Graphviz.
